As data emerges as a core strategic asset for enterprises, the importance of governance and security systems that systematically manage and protect data is increasing. Stricter regulations such as personal data protection laws and telecommunications laws, combined with rising data breach incidents, have made data governance and security critical priorities for IT organizations.

Data governance is a management system that ensures consistency and reliability of enterprise-wide data through data standardization, quality management, and architecture frameworks. Database security protects sensitive data stored in databases from unauthorized access and leakage through access control, encryption, and de-identification.

This section covers data standardization frameworks and quality management processes in public and private sectors, and access control models (DAC, MAC, RBAC) and technologies for encryption, masking, and de-identification.
