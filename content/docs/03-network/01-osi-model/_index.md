Network architecture is designed based on data transmission methods (circuit switching and packet switching) and connection structure (topology), and the OSI 7-layer reference model is a core framework that enables standard communication between heterogeneous systems. This section systematically covers the switching methods and topology that form the foundation of network design, as well as the mapping relationship with the TCP/IP protocol stack.
