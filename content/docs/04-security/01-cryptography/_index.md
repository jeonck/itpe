Cryptography is a set of mathematical techniques for protecting information from third parties and is a core technology field underlying modern information security.  
Systematic study of symmetric-key and asymmetric-key encryption, hash functions, digital signatures, and PKI authentication systems enables achieving the four core security goals: confidentiality, integrity, non-repudiation, and authentication.

| Order | Topic | Core Content |
|:---:|---|---|
| 1 | [Symmetric-Key Encryption](symmetric-crypto) | Block and stream cipher structure and ECB, CBC, CTR operating modes |
| 2 | [Asymmetric-Key Encryption](asymmetric-crypto) | RSA, Diffie-Hellman, ECC mathematical principles and symmetric-key plus asymmetric-key hybrid encryption system architecture |
| 3 | [Hash Functions and Digital Signatures](hash-digital-signature) | SHA-2/SHA-3 hash function collision resistance, HMAC message authentication, digital signature non-repudiation principles |
| 4 | [Public Key Infrastructure (PKI)](pki) | X.509 PKI trust architecture comprising CA, RA, certificate issuance, CRL, OCSP, and certificate lifecycle management |
| 5 | [User Authentication Technologies](authentication) | Four authentication factors: knowledge, possession, inherence, behavior; MFA, FIDO, Passkey |
