Application and development security covers methodologies and tools for identifying and removing security vulnerabilities across all stages of software design, development, and deployment, encompassing the full scope of development security from OWASP-based web vulnerability analysis to Secure SDLC, secure coding, and automated analysis.  
Each topic is structured from attack principles, defense techniques, and practical application perspectives, making it useful for professional engineer exams and practical security development.

## Learning Topics

| Topic | Core Content | Security Domain |
|---|---|---|
| **[Web Application Vulnerabilities (OWASP)](owasp-web-vulnerabilities)** | OWASP Top 10, SQL injection, XSS, CSRF attack principles, detection, defense | Web security, vulnerability analysis |
| **[Software Development Security Lifecycle (Secure SDLC)](secure-sdlc)** | MS-SDL, Seven Touchpoints, CLASP, threat modeling STRIDE/DREAD | Development process security |
| **[Secure Coding and Security Analysis (SAST/DAST/IAST)](secure-coding-sast-dast)** | Seven critical vulnerabilities, SAST, DAST, IAST, RASP comparison, DevSecOps integration | Code security, automated analysis |
