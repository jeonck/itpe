To overcome the limitations of perimeter-based security, modern security paradigms integrating Zero Trust, cloud native, AI-based detection, and supply chain visibility are spreading.  
Through four topics below, you systematically learn core concepts of next-generation security from Zero Trust architecture to SBOM-based supply chain security.

## Learning Topics

| Topic | Core Content | Core Keywords |
|---|---|---|
| **[Zero Trust](zero-trust)** | Never Trust Always Verify principle, SDP implementation model, five guidelines | Least privilege, ZTNA, SPA |
| **[Cloud Security Architecture](cloud-security)** | Shared responsibility model, CWPP, CSPM, CASB, CNAPP, SASE, SSE | CNAPP, SD-WAN, SSE |
| **[AI and Security](ai-security)** | SOAR automation, adversarial attacks, LLM prompt injection | UEBA, evasion, poisoning |
| **[Supply Chain Security and SBOM](supply-chain-sbom)** | Open source vulnerability management, SPDX and CycloneDX standards | CVE, SCA, EO 14028 |
